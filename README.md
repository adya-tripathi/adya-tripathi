## 🚀 Featured Projects

### 🏙️ [Nagar-Drishti](https://github.com/upadhyayom1/Nagar-Drishti)

An ML-powered smart-city monitoring system designed to analyze vehicle movement, detect anomalies, and forecast traffic patterns.
Contributed to the machine-learning layer for movement analysis, hotspot detection, and traffic prediction.

- Implemented movement analysis using Haversine distance and dwell-time thresholds to flag potentially suspicious vehicle activity.
- Applied Isolation Forest for anomaly detection in vehicle movement data.
- Used DBSCAN clustering to identify traffic hotspots from location data.
- Built Markov-based transition analysis to identify likely next locations.
- Developed a Random Forest regression pipeline for short-term traffic forecasting using lag features and rolling statistics.

**Tech:** Python · Pandas · Scikit-learn · Isolation Forest · DBSCAN · Random Forest

### 🎓 [JanSaarthi-AI](https://github.com/upadhyayom1/JanSaarthi-AI)

An AI-powered platform designed to help students discover relevant scholarships and opportunities through eligibility checks and machine-learning predictions.
Worked on the ML service, focusing on scholarship data processing, eligibility logic, and predictive modeling.

- Processed a scholarship dataset containing approximately 245,000 records across 10 scholarships.
- Developed a Random Forest model to estimate scholarship success probabilities.
- Implemented eligibility-based filtering using scholarship-specific rules.
- Integrated model predictions with eligibility information to support scholarship matching.
- Worked on model serialization and deployment-ready artifacts for the ML service.

**Tech:** Python · Pandas · Scikit-learn · Random Forest · Model Serialization

### 🔍 [MicroGuard](https://github.com/adya-tripathi/micro-guard)

An ultra-lightweight industrial anomaly detection system designed to identify unusual patterns in multivariate manufacturing and IoT sensor data.
Built a custom statistical detection pipeline focused on efficient numerical computation and practical anomaly threshold selection.

- Implemented multivariate Gaussian modeling using mean vectors and full covariance matrices.
- Developed vectorized log-likelihood and Mahalanobis-distance computations using NumPy.
- Used a pseudo-inverse to handle potentially singular covariance matrices.
- Tuned the anomaly threshold using F1-score-based evaluation.
- Built an interactive Streamlit dashboard for analyzing incoming data and displaying anomaly results.

**Tech:** Python · NumPy · Pandas · Statistical Modeling · Streamlit

### 🏥 [Health Insurance Premium Predictor](https://github.com/adya-tripathi/health-insurance-premium-predictor)

A machine-learning application that predicts health insurance premiums from customer attributes such as age, BMI, smoking status, and number of children.
Compared regression approaches and developed an interactive interface for exploring predictions and model performance.

- Performed exploratory data analysis to understand feature distributions and relationships.
- Prepared data for regression modeling using relevant customer attributes.
- Trained and evaluated Linear Regression and Random Forest regression models.
- Compared model performance using R² and RMSE.
- Built a Streamlit interface with visualizations to make predictions and model insights accessible.

**Tech:** Python · Pandas · Scikit-learn · Matplotlib · Seaborn · Streamlit
